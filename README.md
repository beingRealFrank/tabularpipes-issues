# Tabular Pipes

Free JetBrains IDE plugin for KQL (Kusto) queries. Works offline: no network calls, no data collection.

[![Downloads](https://img.shields.io/jetbrains/plugin/d/36123)](https://plugins.jetbrains.com/plugin/36123-tabular-pipes)

## Install

In your IDE: **Settings | Plugins | Marketplace**, search for **Tabular Pipes**, then **Install**. Or get it from [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/36123-tabular-pipes).

## Features

- KQL highlighting for `.kql` and `.csl` files
- Structure view, completion and quick documentation
- A formatter that puts each pipe stage on its own line
- Inspections for unbalanced brackets and unknown operators
